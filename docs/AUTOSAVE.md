# 작업 자동 저장

SNUWCANVAS.exe는 변경 사항을 1초마다, 그리고 정상 종료 직전에 자동 저장합니다.
다시 실행하면 프롬프트 각 항목, 네거티브, 참조 이미지 경로·순서·강도·용도, 모든 생성 설정,
선택한 프리셋·표정·탭, 검색어·미리보기 이미지, 창 크기를 복원합니다.

작업 파일은 config/canvas_session.json입니다. 생성 이미지 폴더에는 저장하지 않습니다.
참조 이미지 원본을 이동하거나 삭제하면 해당 이미지를 다시 지정해야 합니다.
진행 중인 서버 생성 요청은 재실행 시 재개하지 않습니다.

v12는 종료 시 타이머와 미리보기 스레드를 정리합니다. 작업 파일이 잠겨 교체할 수 없으면
config/ 안에 canvas_session_recovery_*.json으로 저장하고, 재실행 시 가장 최근 작업을 복원합니다.
폴더 자체에 저장할 수 없는 경우에는 변경 사항을 저장하지 않고 종료할 수 있습니다.
