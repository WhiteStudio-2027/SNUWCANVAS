# 최대 2회 보정

소스 구현 상태이며 최종 통합 검사 전입니다. 아직 새 EXE에 배포하지 않았습니다.

1. 현재 계정·모드의 서버 생성 이미지를 선택합니다.
2. 이미지 검사에 사용할 설치된 비전 모델을 설정합니다. 자동 다운로드하지 않습니다.
3. 오디션 메뉴의 **선택 이미지 · 최대 2회 보정**을 선택하고 추가 생성 사용량을 확인합니다.
4. 검사에서 해부학·흐림·아티팩트 문제가 의심될 때만 제외 태그와 시드를 바꿔 새 후보를 생성합니다.
5. 최대 2장만 추가 생성합니다. 원본·일반 입력·앞선 후보를 덮어쓰거나 자동 삭제하지 않습니다.

검사 모델의 자기 판단은 정답이나 검증된 신뢰도가 아닙니다. 불확실하거나 정체성·화풍·의상 등 다른 문제가 보고되면 자동 생성을 멈추고 수동 확인을 안내합니다.
초기 이미지가 없는 SDXL 계열 생성만 지원합니다. 일반 생성과 같은 서버 권한·검열·사용량 제한을 적용합니다.

메인 **중지** 또는 메뉴의 **보정 중지**로 추가 생성을 멈춥니다.
접수 여부가 불명확한 작업이나 앱 종료 후 중단된 세션은 자동으로 다시 요청하지 않습니다.
**보정 기록 폴더**에는 원본 지문·검사 결과·시도별 요청/작업 ID·후보 경로·실패 이유를 남깁니다.
실제 오류 감소율·동일성·GPU 성능은 측정하지 않았습니다.
