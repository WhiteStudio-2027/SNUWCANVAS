# 자료 이관 관리

소스 구현 상태이며 최종 통합 검사 전입니다. 새 EXE 배포는 아직 하지 않았습니다.

프로젝트 메뉴의 **자료 이관 관리**에서 순서대로 실행합니다.

1. **원본·대상 선택 후 검사**: 이미지 폴더와 사본을 만들 별도 로컬 폴더를 선택합니다. JSON이 분리돼 있으면 해당 원본 폴더도 선택합니다.
2. **검사 결과 보기**: 원본/JSON/대상 경로, 파일 수, 용량, 소유 기록을 확인합니다. 검사는 읽기 전용입니다.
3. **검사한 사본 복사**: 본인 자료이며 현재 계정·모드로 복사할 자료인지 확인합니다. 원본을 다시 검사한 뒤 별도 폴더에 복사합니다.
4. 원본과 사본 SHA가 일치하면 새 폴더를 확정하고 현재 채널 갤러리에 연결합니다.

이미지와 JSON을 별도 하위 폴더에 저장하고 원래 상대 경로와 생성 날짜를 유지합니다.
여러 계정의 기록이 섞인 원본과 하드코어→일반 모드 복사는 중지합니다.
계정 기록이 다르거나 없는 자료는 현재 계정으로 귀속한다는 명시적 확인이 필요합니다.
연결 경로·폴더 중첩·대소문자 충돌·기존 대상·부족한 디스크는 거절합니다.

**복사 기록·연결·롤백**에서 완료/실패 기록을 확인하고, 앱 종료 후에도 사본을 재검사해 다시 연결할 수 있습니다.
롤백은 이 앱이 남긴 개인 계정의 복사 기록으로만 실행합니다. 원본과 SHA가 같은 사본만 삭제합니다.
원본·수정된 사본·새 파일·사용 중인 파일·감사 기록은 보존합니다.
기존 도구로 만든 폴더는 **기존 이관 폴더 연결**을 사용하고, 연결 해제는 파일을 삭제하지 않습니다.

진행 중 이관을 중지하면 이미 만든 임시 사본과 기록을 남깁니다. 원본은 유지됩니다.
파일은 자동으로 온라인 동기화하거나 공개하지 않습니다. 연결 목록의 이전 상태도 별도 백업합니다.
검사/복사/기록 조회/재연결/롤백은 UI와 분리한 한 작업자에서 수행합니다.
