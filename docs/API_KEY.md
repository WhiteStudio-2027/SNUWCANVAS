# 서버 비밀키

생성 설정 탭에서 서버 주소 아래의 **비밀키**에 서버의 API_KEY 값을 입력합니다.
생성 요청과 같은 서버의 이미지 다운로드 요청에 `X-API-Key` 헤더로 전달됩니다.
키가 비어 있으면 헤더를 보내지 않습니다.

**모든 채널의 기본키로 설정**을 누르면 기존 채널의 키를 일괄 변경하고 새 채널에도 적용합니다.
기본키를 지우려면 입력칸을 비운 뒤 같은 버튼을 누릅니다.
개별 채널에서는 입력칸을 수정해 별도의 키를 사용할 수 있습니다.

입력값은 마스킹되고 재실행 시 복원됩니다.
기본키는 `config/credentials.json`, 채널별 키는 작업 설정 파일에 저장됩니다.
외부 이미지 주소에는 서버 비밀키를 보내지 않습니다.
