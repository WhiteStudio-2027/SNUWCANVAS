# 계정 로그인 전환 (Phase 7 진행 중)

이 개발 빌드는 시작 시 이메일과 비밀번호로 로그인한다. 처음 사용하면 새 계정을 만들고 현재 서버의 동의서를 확인한다. 비밀번호는 저장하지 않는다. 접근/갱신 토큰은 `data/config/account_session.bin`에 Windows DPAPI로 보호하며 다른 Windows 계정에서 열 수 없다. 토큰을 다른 서버 주소로 보내지 않는다.

전체설정에서 서버 주소, 자동 업데이트, 스플래시 설정을 변경한다. 계정 등급은 서버 응답으로 표시한다. 로그아웃하면 서버 세션을 종료하고 로컬 세션을 비운 뒤 앱을 닫는다. 서버 연결 실패 시 로컬 로그아웃만 수행했음을 안내한다. 다음 실행 시 로그인 화면이 나온다.

계정 서버는 `ACCOUNT_AUTH_ENABLED=1`과 비공개 `ACCOUNT_MASTER_KEY_FILE` 설정이 필요하다. 현재 운영 설정은 자동으로 바꾸지 않았다. 인증 서버가 아직 활성화되지 않았으면 로그인 화면의 404 안내를 확인하고 서버 준비 후 시험한다. 기존 설치 EXE는 유지한다.

독립 캡션 API의 계정 인증, develop 관리 화면, 반응형 화면 QA는 후속 작업이다. 기존 캡션 자격증명과 레거시 설정 파일을 자동 삭제하지 않는다. 실제 배포 준비가 완료된 것으로 간주하지 않는다.
