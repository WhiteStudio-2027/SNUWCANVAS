# 생성 설정과 예약

화면 배치는 유지하고 검은 테마를 적용했습니다. API 키와 기존 채널 설정은 보존합니다.
너비·높이는 상한 없이 최소 64픽셀과 8의 배수 조건만 유지합니다.

## 고급 생성

서버 옵션 조회를 누르면 서버에 설치된 모델·VAE·LoRA·샘플러·업스케일러 목록과 노드 입력을 확인할 수 있습니다.
고급 입력칸을 비우면 서버 기본값이 사용됩니다. 고급 옵션에는 server/의 최신 서버가 필요합니다.
초기 이미지에서 img2img를 지정하고 Denoise로 원본 유지 정도를 조절합니다.
노드별 입력 JSON은 예를 들어 `{"70":{"steps":35,"cfg":6}}`로 입력합니다.
노드 연결이나 새 노드 추가를 하는 전체 ComfyUI 그래프 편집기는 아닙니다.

## 생성 예약

생성 중 버튼을 누르면 현재 프롬프트·설정·참조 파일 경로·채널을 캡처해 예약합니다.
이후 편집이나 채널 전환은 예약된 요청을 바꾸지 않습니다.
예약은 입력 순서대로 실행됩니다. 참조 원본 파일은 작업이 끝날 때까지 이동·삭제하지 마세요.
상단에 생성 중인 채널과 장수, 예약 건수가 표시됩니다. 서버의 실시간 GPU 진행률은 제공되지 않습니다.
생성 중 다른 채널을 볼 수 있으며 결과는 요청한 채널의 저장 폴더에 저장됩니다.
작업 중에는 채널을 삭제할 수 없습니다.
중지는 대기 예약을 취소하고, 진행 중인 서버 요청은 응답 후 중단합니다.
앱 종료 시 예약은 취소되며 서버 요청 자체를 취소하거나 재시작 후 재개하지 않습니다.
