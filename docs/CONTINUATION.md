# 이어갈 작업 기준

출처: https://claude.ai/share/399d4e18-b9e2-442b-947d-69da760ba07d

## 공유 대화에서 확인한 최신 목표

- 갈색/밤색 긴 머리, 끝부분의 부드러운 웨이브, 가운데 갈라지는 긴 앞머리와 옆머리.
- 회청색 눈, 차분한 표정, 다문 입과 희미한 미소, 작은 귀걸이.
- 흰 무지 티셔츠, 열린 버건디 과잠, 크림/아이보리 소매, 빨강·흰색 줄무늬 시보리, 스냅 단추.
- 정면 상반신, 수평인 눈과 어깨, 팔을 내린 자세, 단순한 흰 배경. Live2D 원화와 파츠 분리 고려.
- 캐릭터 / 의상 / 장면·자세 / 화풍 / 기타 / 네거티브를 분리해 작성.
- 기타도 프롬프트 입력칸이며 생성 설정값은 넣지 않음.
- 마지막 요청은 각 항목을 구체적으로 늘리고 인터넷에서 태그를 조사하는 것이었음.
  최종 응답은 각 탭에 많은 태그를 제공했지만 '각각 100줄 이상' 요구를 충족했다고 검증된 것은 아님.

## 남은 확인 사항

- 공유 페이지의 첨부 이미지는 숨겨져 있어 실제 캐릭터 외형을 직접 확인하지 못함.
- 생성 서버의 모델·VAE·샘플러·Steps·CFG와 프롬프트 파서 문법은 아직 확인되지 않음.
- 공유 대화에서 제안한 832×1216, CFG 5, Steps 28 등의 값은 이전 답변의 제안이며 현재 서버에서 검증된 설정이 아님.
- 이미지 깨짐 원인에 관한 이전 답변은 가설임. 출력과 실제 서버 설정을 보고 확인해야 함.
- 과거 푸리나 프롬프트와 새로운 갈색 머리 캐릭터를 혼합하지 않음.
- 이전 소매 조건: 팔의 흰 패널에 빨간 줄 금지, 시보리의 줄은 허용. 최신 과잠 작업에도 적용할지는 다음 지시로 확인.

## 현재 프로젝트

앱 이름 SNUWCANVAS. 실행파일은 루트의 SNUWCANVAS.exe, 소스는 client/src/native/main.cpp.
채널별 작업/이미지, 자동 저장, 프롬프트 항목 분리, 참조 이미지, API 비밀키 입력을 지원.
너비·높이 최대 제한은 제거됨. 최소 64픽셀과 8의 배수 조건은 유지.

다음 작업 지시를 받기 전에는 현재 채널·프롬프트·이미지와 서버 설정을 변경하지 않음.
