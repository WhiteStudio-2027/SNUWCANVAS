# 캐릭터 참조 시트

1. 개발자 계정에서 캐릭터 프로필을 선택합니다.
2. 같은 계정·모드의 정면 원본을 선택하고 **참조 시트 → 새 시트**를 누릅니다.
3. 정면·왼쪽·오른쪽·후면 후보가 한 장씩 생성됩니다. 사용량은 생성한 4장에 적용됩니다.
4. 각도를 선택하면 오른쪽에 크게 표시됩니다. 실제 외형을 확인한 뒤 **외형 확인** 또는 **거절**을 선택합니다.
5. 확인한 후보만 **참조로 추가**하거나 원래 프로필의 **학습에 추가**할 수 있습니다. 이미지 추가만으로 학습을 시작하지 않습니다.

현재 모델과 설정을 사용하지만 일반 입력 프롬프트는 바꾸지 않습니다. 픽셀아트 모델은 지원하지 않습니다. 서버에 해당 모델의 참조 이미지 어댑터가 준비되어 있어야 합니다. 이 기능이 어댑터나 모델을 자동 다운로드하지는 않습니다.

모든 각도는 생성한 가설이며, 특히 후면의 보이지 않는 부분은 추정입니다. 외형 확인은 사용자의 검토 기록이며 실제 정답 데이터로 바꾸는 기능이 아닙니다.

원본 SHA256, 프로필 버전, 생성 모드를 고정합니다. 준비 중 계정·모드·프로필·설정을 바꾸거나 원본 파일이 바뀌면 기존 준비 결과를 적용하지 않습니다. 후보 파일이 바뀌면 확인 상태도 해제됩니다.

일시정지는 현재 요청을 마친 뒤 멈춥니다. 다시 실행하면 알려진 작업 상태를 조회하며, 접수 여부가 불명확한 요청을 자동으로 중복 전송하지 않습니다. 시트 기록은 계정별 로컬 저장이며 자동 온라인 동기화하지 않습니다.


## 카메라 5구도

같은 화면의 **구도·화풍 → 카메라 5구도**는 얼굴 클로즈업·3/4·전신·높은 시점·낮은 시점 후보를 생성합니다.
캐릭터 프로필 버전과 정면 참조를 고정하고 모델 설정은 현재 값을 사용합니다.
확인 창에 표시한 5장 사용량을 승인한 뒤 시작하며, 일반 프롬프트는 덮어쓰지 않습니다.
결과는 기존 오디션 목록에서 구도별로 선택·평가하고 큰 미리보기로 확인합니다.
생성 후보는 동일인임을 자동으로 보장하거나 승인한 자료로 취급하지 않습니다.


## 같은 캐릭터의 화풍 비교

일관성 설정에서 화풍 프로필을 선택한 뒤 **구도·화풍 → 화풍 비교**를 선택합니다.
기본 후보와 선택 화풍 적용 후보를 각각 한 장 생성합니다. 캐릭터 프로필·정면 참조·시드·모델 설정을 같게 유지하고 화풍만 달리합니다.
캐릭터와 화풍의 콘텐츠 버전을 서버에서 확인하며, 화풍 프로필이 없거나 변경됐으면 시작하지 않습니다.
오디션에서 첫 후보를 **비교 기준 A**로 지정하고 다른 후보를 **A/B 비교**로 확인할 수 있습니다.
서로 다른 시드나 캐릭터 기준의 후보를 이 화풍 비교 쌍으로 취급하지 않습니다.
결과의 닮은 정도는 직접 확인해야 하며 원본·일반 프롬프트·화풍 프로필을 덮어쓰지 않습니다.
