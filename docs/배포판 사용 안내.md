# SNUWCANVAS

SNUWCANVAS.exe를 실행하고 생성 설정에서 서버 주소와 발급받은 비밀키를 입력하세요.
배포 파일에는 개인 API 키, 프로젝트, 생성 이미지가 포함되지 않습니다.
코드 서명 인증서는 적용되지 않아 Windows가 실행 확인을 표시할 수 있습니다.

가운데 이미지 작업 공간, 왼쪽 프로젝트 목록, 오른쪽 프롬프트·참조·생성 설정으로 구성됩니다.
프로젝트 관리 메뉴에서 닫기/다시 열기/가져오기/내보내기를 사용할 수 있습니다.
Ctrl+S 저장, Ctrl+N 새 프로젝트, Ctrl+O 프로젝트 파일 열기, Ctrl+W 닫기.
변경 사항은 5초마다 자동 저장됩니다. 창을 닫을 때도 저장합니다.
프로젝트 내보내기에는 서버 주소와 비밀키를 제외합니다. 참조 이미지는 파일 경로만 저장하므로 다른 PC로 옮길 때 함께 옮겨주세요.

상단에서 빠르게/균형/고품질/사용자 지정과 애니/실사를 선택합니다.
애니/실사 선택은 태그와 CLIP 레이어 설정을 바꿉니다. 모델을 자동 다운로드하지 않습니다.
고급 생성의 서버 옵션 조회 후 해당 SDXL 체크포인트를 직접 선택하세요.
빠르게와 균형은 추가 보정을 끕니다. 고품질은 두 번째 보정이 있어 더 오래 걸립니다.
너비·높이에 최대 제한을 추가하지 않았으며, 실제 가능한 크기는 서버 VRAM에 따라 달라집니다.

생성 중 버튼을 다시 누르면 다음 작업을 예약합니다. 프로젝트를 이동해도 생성이 계속되며 생성 중인 프로젝트 삭제는 제한됩니다.
다른 사용자와 같은 서버를 쓰면 각각 1장씩 교대로 생성합니다. 새 서버 배포본을 함께 적용해야 이 기능이 활성화됩니다.

배포판 데이터는 EXE 옆 data/에 저장됩니다. ZIP에는 EXE 하나만 포함되어 새 폴더에서 실행하면 빈 상태로 시작합니다.
기존 exe 옆 config/prompts가 있으면 최초 실행 시 복사하며, 기존 생성 이미지 경로는 유지합니다.
별도 데이터 폴더는 SNUWCANVAS_DATA_DIR 환경변수로 지정할 수 있습니다.
