# 이름 지칭어

등록한 프로필은 `$하루$`, `$도서관$`처럼 이름 양쪽에 `$`를 붙여 사용한다. `$`를 입력하면 자동완성 목록이 열리며, 목록에서 선택하거나 프로필 삽입 기능을 사용하면 `$이름$`이 들어간다.

가중치 `(blue eyes:1.2)`는 그대로 사용할 수 있다. 지칭어에도 `($하루$:1.2)`처럼 가중치를 붙일 수 있다. 기존 `:이름:`은 지칭어로 해석하지 않으므로 필요한 항목만 직접 `$이름$`으로 바꾼다. 기존 프로필과 프롬프트 파일은 자동 변환하거나 삭제하지 않는다.

일반 문자로 `$이름$`을 적으려면 `\$이름$`처럼 쓴다. 프로필 이름에는 `$`를 넣을 수 없다. 서버도 함께 업데이트해야 새 지칭어가 생성 요청에서 정상 해석된다.
