# SNUWCANVAS 채널

왼쪽 채널 목록에서 원하는 채널을 클릭하면 프롬프트와 생성 이미지를 바로 불러옵니다.

- **새 채널**: 이름을 입력하고 프롬프트를 작성합니다. 기본 네거티브는 현재 내용에서 이어받습니다.
- **채널 저장**: 현재 내용을 즉시 저장합니다. 평소에는 1초마다 자동 저장됩니다.
- **채널 복제**: 프롬프트·참조·설정을 복사하고 별도 이미지 폴더를 만듭니다.
- **이름 변경 / 고정**: 목록에서 쉽게 찾을 수 있도록 정리합니다.
- **채널 삭제**: 확인 후 채널을 삭제합니다. 생성 이미지 파일은 보존됩니다. 마지막 채널을 삭제하면 빈 채널이 만들어집니다.
- 검색 입력창에서 채널 이름을 검색할 수 있습니다.

기존 프리셋은 첫 실행 때 채널로 가져옵니다. 기존 이미지들은 **기존 작업** 채널의 저장 폴더에서 볼 수 있습니다.
기존 이미지의 프롬프트를 임의로 추측해서 분류하지 않습니다.
새 채널의 이미지는 `generated/<채널 ID>/`에 저장합니다. 생성 설정에서 다른 저장 폴더를 지정할 수도 있습니다.
채널 목록과 작업 내용은 `config/channels.json`에 저장됩니다.

생성 중에도 채널을 전환하고 새 채널을 만들 수 있습니다. 생성 결과는 요청할 때 지정한 채널에 저장합니다. 생성·예약 작업 중에는 채널을 삭제할 수 없습니다.
앱 이름은 **SNUWCANVAS**, 기본 생성 버전과 파일 접두사는 **v9**입니다.
