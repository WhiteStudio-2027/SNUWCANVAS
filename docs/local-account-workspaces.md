# 계정별 로컬 작업 공간

로그인 API가 반환한 account_id와 서버 origin을 SHA256으로 묶고 경로에는 앞 32자만 사용해 `<data>/local_accounts/<hash>/` 아래 계정별 channels/config/prompts/generated를 저장한다. 로그인 세션/기기 식별자는 기존 data/config에 유지한다. 기본서버 주소와 자동 업데이트/스플래시 설정만 시작 설정에서 공유하고 생성 설정·작업 공간 배치·프롬프트·프리셋·갤러리는 계정별로 불러온다.

로그아웃은 계정 데이터 삭제가 아니라 화면 캐시를 비우고 signed-out 작업 공간으로 이동하는 동작이다. 같은 계정으로 돌아오면 그 PC에 저장한 채널/설정/이미지를 복원한다. 서버의 계정을 삭제 후 같은 이메일로 다시 만들어도 account_id가 달라 새 공간을 사용한다. 온라인 채널 동기화/자동 이미지 내려받기는 추가하지 않는다. 개발자가 API로 이미지를 명시적으로 다운로드하면 현재 로그인 계정의 로컬 복사본으로 저장한다.

공통 외부 출력 폴더를 지정해도 현재 계정이 저장한 이미지 소유 기록(config/owned-images)으로 갤러리를 제한한다. 다른 계정의 전용 작업 공간에 직접 출력하는 것도 차단한다. 늦게 도착한 이전 계정의 작업/조회 이벤트는 채널 식별자 기준으로 버린다. 실제 Windows 파일 접근 권한을 별도 OS 사용자처럼 격리하거나 파일을 암호화하는 기능은 아니다.

업데이트 이전 공용 config/channels.json·prompts·generated는 소유 계정을 확정할 수 없으므로 어떤 계정에도 자동 이관하지 않고 원래 위치에 보존한다. 필요한 과거 프로젝트는 소유자가 확인한 뒤 프로젝트 JSON 가져오기로 명시적으로 추가할 수 있다. 기존 이미지는 필요한 것만 직접 복사/가져오거나 서버 API에서 내려받아야 한다. 다른 계정에 과거 공용 데이터가 자동 노출되지 않는 것이 우선이다.
