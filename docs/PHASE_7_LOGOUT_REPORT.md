# Phase 7 보완 — 전체 기기 로그아웃

- 변경 요약: 전체설정 로그아웃 메뉴에 현재 기기/모든 기기를 구분했다. 전체 기기는 추가 확인 후 기존 logout-all API를 호출한다. 응답 전 프로젝트를 바꿔도 전역 로그아웃 처리가 생략되지 않도록 수정했다.
- 주요 파일: `account_session.hpp`, `api.hpp`, `global_ui.hpp`, `learning_ui.hpp`, `app.cpp`, `tests/test_account_session_client.py`.
- DB/env: 변경 없음. 기존 회전 세션·폐기 API와 DPAPI 로컬 세션을 사용한다. 실제 세션은 종료하지 않았다.
- 테스트: 개발용 EXE 빌드 성공. 새 EXE의 가짜 HTTP 세션/숨김 개발자 표 테스트 2개 통과(1.381초). logout-all 경로/빈 JSON/Bearer/기기 헤더, 키 비전송, 회전 1회, 로컬 세션 삭제를 검사했다. 직전 전체 회귀는 213개 통과이며 이 작은 UI 변경 후 집중 검사만 수행했다.
- 설계 결정: 하단 버튼을 늘리는 대신 메뉴로 분리했다. 기존과 같이 완료 후 앱을 닫고 다음 실행에서 로그인한다. 서버 종료 응답을 못 받아도 로컬 세션 삭제와 미확인 안내를 유지한다.
- 추가 제안 기능: 채널 전환 중 전역 세션 완료 이벤트 유실 방지.
- 한계: 실제 클릭/DPI/원격 계정 세션 검증은 미수행. 설치 EXE/설정/공개 배포/push 변경 없음.

법률 검토를 받은 문서가 아니므로 서비스 공개 전 전문가 검토 필요.
