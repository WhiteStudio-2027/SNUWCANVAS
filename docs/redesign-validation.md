# v3.5 개편 검증

2026-11-09

- 엔진/모델/참조/설정이 호환되는 로컬 우수 결과에서 시드 추천·명시 적용·되돌리기.
- 원본을 유지하는 최대 2회 보정과 진행·중단·로컬 기록.
- 학습 모델 버전 목록·선택·해제와 관리자 로컬 모델 파일 전송.
- 계정별 이관 관리: 검사→복사→검증→연결, 개인 기록과 보수적 롤백.
- 승인된 내장 manifest 배경만 표시한다. 현재 승인 항목이 없어 검은 정적 배경을 사용한다.
- 기존 클라이언트 회귀 43건 통과. 추가 독립 네이티브 검사 1건 통과.
- 추가 검사는 이미지/JSON 복사·원본 보존·변경/신규 파일 롤백 보존·타계정 거절·시드 정렬을 실행한다.
- 실제 GPU/깨끗한 OS/초보자 사용성·사람 동일성 점수는 미측정이다.
- 테스트는 운영 자료와 분리한 임시 파일을 사용했다. 기존 자료·백업은 삭제하지 않는다.
