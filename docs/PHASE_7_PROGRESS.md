# Phase 7 진행 기록 (미완료)

Phase 6 보고·로컬 커밋 이후 순서대로 진행 중이다.

## 이번 범위
- 비동기 이메일 로그인/가입, 서버 동의서 확인, 오류 안내와 요청 취소를 추가했다.
- Windows DPAPI로 토큰을 설정 JSON과 분리하고 같은 서버에만 Bearer를 보낸다.
- 갱신 토큰 회전을 mutex로 직렬화해 동시 요청의 이중 갱신을 막는다.
- API 키 입력 UI를 제거하고 서버가 제공하는 계정 등급/이메일 표시와 로그아웃을 연결했다.
- 커뮤니티는 비활성 진입점만 둔다.

## 전환 조건
이 빌드의 일반 GUI는 계정 인증 서버가 필요하다. 서버의 ACCOUNT_AUTH_ENABLED 및 마스터 키 파일 준비는 운영자가 별도로 해야 한다. 기존 설치본과 실제 env/사용자 설정은 도구로 변경하지 않았다. 독립 캡션 API는 기존 설정을 보존하지만 계정 인증 통합이 아직 남아 있다.

## 남은 범위
develop 관리 화면과 서버 관리 API 보강, 창 크기별 로그인/관리 화면 정리, 캡션 계정 인증 경계, 통합 회귀 및 최종 Phase 7 보고가 남아 있다. 실제 창을 열어 수행한 QA는 없다. 이 파일은 Phase 7 완료 보고가 아니다.

## 이번 검증
최종 네이티브 빌드 성공. 클라이언트 회귀 14개 모두 통과(10.666초). 새 세션 테스트는 임시 DPAPI 파일, 가짜 로컬 HTTP 서버, 동시 요청 2개에 대한 갱신 1회, Bearer 전송·API 키 비전송, 다른 origin 차단 및 로컬 로그아웃을 검사했다. 기존 생성·다운로드·중지·설정·그리드 테스트도 통과했다. 취소 테스트의 가짜 서버에 ConnectionResetError가 출력됐지만 테스트 실패는 없었다. 운영 API·GUI 로그인·배포는 실행하지 않았다.

법률 검토를 받은 문서가 아니므로 서비스 공개 전 전문가 검토 필요.
