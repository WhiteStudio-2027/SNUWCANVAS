# 작업 공간 크기 조절

이미지 영역 상단의 **크기** 메뉴에서 설정 패널 너비, 프로젝트 패널 너비, 갤러리 너비 비율, 썸네일 목표 크기, 창 크기를 입력한다. 자동 배치로 초기화도 제공한다. 설정/이미지 경계, 펼쳐진 프로젝트 경계, 갤러리/미리보기 경계를 마우스로 드래그할 수도 있다. 좁은 창에서는 최소 패널 크기에 맞춰 표시값을 제한하되 원래 지정값은 유지하므로 다시 넓히면 복원한다.

배치 설정은 config/canvas_settings.json의 _workspace_layout에 전역 저장되며 채널의 생성 설정과 독립적이다. 창 위치/크기는 기존 채널 세션 geometry에 저장한다. 픽셀아트 출력 해상도와 화면 미리보기 크기는 별도다.

리사이즈는 창 이동 루프에서 최대 약 60Hz로 합치며 크기 변경이 없을 때 렌더 타깃을 재할당하지 않는다. 네이티브 입력 컨트롤 위치는 DeferWindowPos로 묶고 바뀐 좌표만 적용한다. 창 크기를 바꿀 때 툴팁/입력 컨트롤을 다시 생성하지 않는다. 드래그 중에는 디스크 자동 저장과 이미지 폴더 재검색을 미루며, 패널 지정값은 드래그 완료 시 저장한다. 좁은 이미지 패널에서는 하단 버튼을 두 줄로 배치한다.

테스트는 숨김 네이티브 창에서 100/150/200% 배율, 1040x640·1440x900·1920x1080, 10개 페이지의 90개 조합과 반복 크기 변경을 확인한다. 실제 모든 디스플레이/드라이버 조합에서 무지연을 보장하는 수치는 아니다.
